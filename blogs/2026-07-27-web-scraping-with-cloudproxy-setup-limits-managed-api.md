Web scraping with CloudProxy means running a free, open-source proxy pool on cloud accounts and asking its API for a working proxy whenever the scraper needs one. It is a good fit for cheap, light scraping, but every IP still comes from a data center, so protected sites may block it, and CloudProxy cannot render JavaScript. CloudProxy handles the annoying infrastructure bits.
