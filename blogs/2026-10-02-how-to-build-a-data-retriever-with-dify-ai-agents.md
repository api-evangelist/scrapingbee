Dify AI is an open-source platform for building LLM applications, agentic workflows, and RAG systems. A Dify Agent node can use a live data retriever, a tool that fetches web pages through ScrapingBee's Remote MCP server on request. A live data retriever is different from Dify's Knowledge Retrieval node, which searches documents you indexed earlier.
