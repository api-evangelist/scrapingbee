The interactive REPL for ScrapingBee CLI is now available. The ScrapingBee CLI already lets you run scraping, search, crawl, and extraction commands from your terminal. Now you can do it from a full-screen terminal interface built for testing requests, viewing results, monitoring credits, and reusing settings without leaving the command line.
